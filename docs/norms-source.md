# Источник норм витаминов и минералов

**МР 2.3.1.0253-21** «Нормы физиологических потребностей в энергии и пищевых
веществах для различных групп населения Российской Федерации» (Роспотребнадзор,
22.07.2021). PDF: ФИЦ питания и биотехнологии, web.ion.ru. Ниже — выдержка из
таблиц 9–17 (взрослые старше 18 лет), по которой написан `src/domain/norms.ts`.

Отступления от МР (осознанные):
- Калории — не таблица по группам КФА, а Миффлин — Сан Жеор × коэффициент
  активности ± поправка на цель (цель в МР не учитывается).
- Белок — г/кг по цели (1,4 удержание, 1,8 снижение/набор) вместо 12–14 % калорий;
  МР задаёт минимум 0,83 г/кг — наши нормы выше.
- Натрий — предупреждаем по верхнему пределу ВОЗ 2000 мг/сут, а не по
  физиологической потребности 1300 мг из МР.
- Омега-3 — нижняя граница диапазона 1–2 % калорий.
- Витамин A в USDA — RAE (мкг рет. эквивалента активности), в МР — «мкг рет. экв.»;
  считаем их сопоставимыми.
